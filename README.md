# Home Assistant Add-ons

Custom Home Assistant add-ons.

## Mysa2MQTT

Runs bourquep/mysa2mqtt as a Home Assistant add-on.

## EDC Planner (Android app)

`edc-planner/`: an offline set-time planner for EDC Orlando 2026. Install it from `edc-planner/EDC-Planner.apk`; see [edc-planner/README.md](edc-planner/README.md).

## edc-sync (live crew server)

`edc-sync/`: a small Docker server that live-syncs EDC Planner crews. It comes with an Unraid template and Cloudflare Tunnel setup; see [edc-sync/README.md](edc-sync/README.md).
